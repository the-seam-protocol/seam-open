# Bio-Leaching — Battery Recycling (R&D)

> Biological battery recycling targeting high material recovery. **Lab-stage research** — published studies show ~90% recovery for a *single* metal (e.g. lithium) but substantially less for others (e.g. ~50% for manganese); multi-metal, pilot-scale recovery is unproven.

## Biological Agents
- **Acidithiobacillus ferrooxidans** — Iron-oxidizing bacteria
- **Aspergillus niger** — Citric acid-producing fungi

## Organic Acid Sources
- Sugarcane waste → fermentation → citric acid
- Citrus waste → fermentation → gluconic acid
- **Zero imported chemicals**

## Reaction
```
LiFePO₄ + organic acid + bacteria → Li⁺ + Fe³⁺ + PO₄³⁻ → direct reuse in assembly lines
```

## Recovery Rate (research target)
**~90% for a single metal (lab-scale)** — lower for multi-metal recovery; full closed-loop recovery is an R&D goal, not a demonstrated rate.

## Status
🔴 **Not started** — Requires lab-scale validation of acid concentrations and bacterial cultures.
