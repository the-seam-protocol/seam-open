# Skateboard Chassis — Universal EV Platform

> The shared platform underneath every S.E.A.M vehicle.

## Key Features

- **Axial-flux e-Axle**: High power density, hermetically sealed (50°C+), minimal maintenance (no routine servicing; bearings are the main long-term wear item)
- **Modular battery bay**: Sub-3-minute hot-swap, standardized connector
- **Universal body mount**: Supports trike, van, and bus bodies
- **Desert-hardened**: Sand ingress protection, thermal management for extreme heat
